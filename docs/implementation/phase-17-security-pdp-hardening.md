### PR-105 - CSP Final + Security Headers + Rate Limit per Endpoint

#### Objective

**Sapuan header keamanan + limit khusus auth/apply/AI.**

Bisnis: kepercayaan pengguna atas platform yang menyimpan data spesifik. Teknis: CSP ketat final, HSTS, nosniff, frame-deny, referrer-policy; rate limit granular per endpoint sensitif (SDD §8.4).

#### Scope

* CSP final (tanpa unsafe-inline; nonce bila perlu)
* Review limit semua mutasi + endpoint sensitif
* Update nginx (PR-098) selaras

#### Technical Notes

**Backend Changes:**

* `core/http` headers final + limiter granular.

**Frontend Changes:**

* Aset selaras CSP (tanpa inline script/style liar).

**Database Changes:**

* Tidak ada.

**API Changes:**

* Tidak ada (perilaku 429 per endpoint terdokumentasi).

**Security Considerations:**

* Inilah PR-nya: CSP, HSTS, rate limiting granular, anti-clickjacking; verifikasi eksternal (Observatory-equivalent).

**Testing Checklist:**

* [ ] Unit Test (konfigurasi limiter)
* [ ] Integration Test (429 per endpoint + header snapshot)
* [ ] E2E Test (regresi alur inti)
* [ ] Accessibility Test (N/A)
* [ ] Manual Verification (scan eksternal staging)

**Deliverables:**

* Postur keamanan HTTP final

**Out of Scope:**

* WAF khusus (Cloudflare default memadai untuk MVP).

**Rollback Strategy:**

RB-Std; header dapat dilonggarkan via config env darurat (dicatat sebagai insiden proses).

#### Acceptance Criteria

* [ ] Header scan grade A di staging (bukti terlampir).
* [ ] CSP tanpa `unsafe-inline`/`unsafe-eval` (web tetap berfungsi penuh).
* [ ] Limit khusus: /auth/*, /jobs/:id/apply, /ai/* — teruji 429.
* [ ] Tidak ada regresi fungsional (E2E penuh hijau).
* [ ] Snapshot header di test (regresi terkunci).

#### Dependencies

* PR-098
* PR-078

#### Risks

* CSP memecah fitur (SSE, media R2). Mitigasi: connect-src/media-src eksplisit + E2E penuh sebelum merge.
